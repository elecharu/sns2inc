# Common Component Protection Rule

프로젝트 공통 컴포넌트의 안정성을 보장하고 예기치 않은 부작용(사이드 이펙트)을 방지하기 위해 다음 원칙을 절대적으로 준수합니다.

### 1. 공통 컴포넌트(공통 소스코드 / 공통 DB 객체) 임의 변경 절대 금지
- 프로젝트 공통 컴포넌트는 전체 시스템 및 모든 업무 화면에서 공통으로 참조하는 핵심 자산입니다.
  - **공통 스크립트 라이브러리**: `Script/` 디렉터리 내 파일들 (`ItsCombo.js`, `ItsGrid.js` 등)
  - **C# 공통 모듈 및 공통 팝업**: `00.Common/`, 공통 팝업 페이지 등
  - **공통 DB 객체**: 공통 프로시저(`DC_FIND`, `DC_COMBO` 등), 공통 함수(`GPCD` 등), 공통 테이블/뷰
- 특정 개별 화면의 요구사항이나 개발 편의를 위해 **공통 컴포넌트의 소스코드나 DB 객체를 임의로 수정/변경하는 행위를 절대 금지합니다.**

### 2. 개별 화면 요구사항의 독립적 처리
- 공통 영역의 임의 변경은 시스템 전체 화면에 광범위한 결함과 회귀 버그를 유발할 수 있으므로 절대 임의로 건드리지 않습니다.
- 개별 화면의 요구사항은 반드시 해당 화면 전용 소스 파일(`.js`, `.aspx`) 및 해당 화면 전용 프로시저 내에서 독립적으로 처리합니다.
