# Feature Spec Explanation Rule (기능별 테이블·값 명세)

화면·프로시저 기능을 작성하거나 수정할 때, 각 기능이 **어느 화면 영역에서, 어떤 테이블을, 어떤 조건·값으로** 사용하는지 정리하며 작업하고, 작업이 끝난 뒤 설명할 때 아래 형식으로 누구나 바로 이해할 수 있게 전달합니다.

---

### 1. 적용 대상 및 시점
- **대상**: 프로시저(`.sql`) 분기 작성·수정, 화면(`.aspx`, `.js`)의 그리드·버튼·팝업 기능 작성·수정
- **작업 중**: 기능별로 참조 테이블, 고정 조건 값(코드값), 표시 컬럼, 연동 동작을 정리하며 진행합니다. 요청에 없는 값을 임의로 정하지 않고, 요청·기존 소스·테이블에서 확인한 값만 사용합니다.
- **작업 후**:
  - 사용자에게 결과를 설명할 때 [2. 작성 형식]의 기능별 명세를 반드시 포함합니다.
  - `WORK_HISTORY.md` 해당 작업의 **작업 내용**에도 같은 형식으로 기록합니다 (`history_tracking.md` 연계).

---

### 2. 작성 형식
- 기능 단위로 번호를 붙입니다: `1. 조회`, `2. 저장`, `3. 삭제` ...
- 기능 안의 세부 항목은 `1)`, `2)` ... 로 나열하고 `대상/영역 : 내용` 형태로 씁니다.
- 한 줄에 한 가지만 쓰고, 문장 대신 명사형으로 간결하게 씁니다.

| 항목 | 쓰는 내용 | 예 |
| :--- | :--- | :--- |
| 대상 데이터 | 업무 데이터명, 참조 테이블, 고정 조건 값 | `반품입고이력 조회 : COMOUT, COMOUTLOT (OUTTP = '40')` |
| 화면 영역 | 그리드·패널·팝업명, 원본 테이블, 표시 컬럼(화면 표시명) | `좌측그리드 : COMOUT (입고일자, 거래처, 품목코드)` |
| 다른 테이블 값 | 코드 대신 이름 등 다른 테이블에서 가져오는 값은 괄호로 표시 | `처리자(사원명)` |
| 연동 동작 | 어떤 동작이 어떤 조회·저장을 일으키는지 | `좌측그리드 선택시 우측그리드 조회` |
| 저장·삭제 | 대상 테이블, 넣는 고정 값, 막는 조건 | `반품입고 저장 : COMOUT, COMOUTLOT (OUTTP = '40')` |
| 프로시저 분기 | 기능이 호출하는 프로시저·CALLTYPE | `프로시저 : SAL1004_R01 / LIST_SALRETURN` |

---

### 3. 작성 원칙
- **실제 이름 그대로 표기**: 테이블명·코드값은 소스에 쓴 그대로 적습니다 (`COMOUT`, `OUTTP = '40'`). 컬럼은 화면 표시명으로 적고, 헷갈릴 수 있는 값만 괄호에 원본을 덧붙입니다.
- **추측 금지**: 확인되지 않은 테이블·값·조건은 채워 넣지 않고 `(미정)` 또는 `(확인 필요)`로 표시합니다.
- **변경 작업**: 바뀐 기능만 같은 형식으로 쓰고, 달라진 부분은 `기존 → 변경`으로 표시합니다 (예: `2) 우측그리드 : COMOUTLOT (로트번호, 반입수량 → 로트번호, 반입수량, QR코드 보기)`).
- **소스 붙여넣기 금지**: 쿼리·스크립트 원문 대신 위 형식으로 요약합니다. 파일 위치는 명세 아래에 링크로만 안내합니다.

---

### 4. 작성 예시
```
1. 조회

1) 반품입고이력 조회 : COMOUT, COMOUTLOT (OUTTP = '40')
2) 좌측그리드 : COMOUT (입고일자, 거래처, 품목유형, 품목코드, 품명, 규격, 처리자(사원명))
3) 우측그리드 : COMOUTLOT (로트번호, 반입수량, QR코드 보기)
4) 좌측그리드 선택시 우측그리드 조회

2. 저장

1) 반품입고 저장 : COMOUT, COMOUTLOT (OUTTP = '40')
2) 저장 전 확인 : 반입수량 0 이하 저장 불가
3) 저장 후 좌측그리드 재조회
```

`WORK_HISTORY.md`에는 **작업 내용** 아래에 같은 내용을 목록으로 기록합니다:
```
- **작업 내용**
  - 1. 조회
    - 1) 반품입고이력 조회 : COMOUT, COMOUTLOT (OUTTP = '40')
    - 2) 좌측그리드 : COMOUT (입고일자, 거래처, 품목유형, 품목코드, 품명, 규격, 처리자(사원명))
    - 3) 우측그리드 : COMOUTLOT (로트번호, 반입수량, QR코드 보기)
    - 4) 좌측그리드 선택시 우측그리드 조회
```
